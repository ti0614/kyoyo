日本史の流れ図　詳説 2／5

中世1185〜1573

武士が初めて政権を握ってから、その力が全国の大名へと分かれていくまでの約390年。政治と外交の動きを中心に、「なぜそうなったか」をたどります。

鎌倉幕府の成立

1180〜1199政治

平氏の政権に不満を持つ武士たちが各地で立ち上がる中、伊豆に流されていた源頼朝みなもとのよりともは1180年に挙兵し、鎌倉を拠点に東国の武士をまとめました。頼朝は自ら京都へは上らず、弟の義経よしつねらに平氏を追わせながら、鎌倉で武士を組織することに力を注ぎます。

1185年に平氏が滅ぶと、頼朝は朝廷に迫って、国ごとに守護しゅご、荘園しょうえんや公領こうりょうごとに地頭じとうを置く権利を認めさせました。これで頼朝の家来（御家人ごけにん）が全国の治安と年貢の取り立てに関わるようになります。教科書でこの年を幕府の成立とすることが多いのはこのためです。1192年には征夷大将軍せいいたいしょうぐんに任じられました。

ただし、朝廷がなくなったわけではありません。京都には天皇・上皇じょうこうと貴族がいて、国司こくしや荘園領主として西日本を中心に支配を続けていました。鎌倉時代の前半は、朝廷と幕府が並び立つ二元的な支配だったのです。

  • 1180頼朝が伊豆で挙兵、鎌倉に入る（侍所を設置）
  • 1185壇ノ浦だんのうらの戦いで平氏滅亡／守護・地頭の設置を認めさせる
  • 1189奥州藤原氏おうしゅうふじわらしを滅ぼす
  • 1192頼朝が征夷大将軍に
2

承久の乱じょうきゅうのらんと執権しっけん政治

1199〜1268政治

1199年に頼朝よりともが亡くなると、有力な御家人ごけにんどうしの争いが続きます。その中で頼朝の妻北条政子ほうじょうまさこの実家である北条氏が、執権として実権を握りました。1219年に3代将軍の源実朝みなもとのさねともが暗殺されて源氏の将軍が絶えると、幕府は京都の貴族の子を名目上の将軍として迎えます。

これを幕府を倒す好機と見たのが後鳥羽上皇ごとばじょうこうです。1221年、上皇じょうこうは北条義時ほうじょうよしときを討つよう命令を出しました（承久の乱）。朝廷の命令に御家人が従うかが焦点でしたが、政子が頼朝の恩を説いて御家人を結束させたと伝えられ、幕府軍はわずか1か月ほどで京都を制圧します。

勝った幕府は3人の上皇を流罪にし、天皇を退位させ、上皇方の領地3000か所あまりを取り上げて御家人に分け与えました。京都には六波羅探題ろくはらたんだいを置いて朝廷を見張ります。こうして力関係は逆転し、幕府の支配は西日本にも広がりました。

3代執権の北条泰時ほうじょうやすときは、執権を補佐する連署れんしょと、有力御家人による評定衆ひょうじょうしゅうを置き、話し合いで政治を進める仕組みを整えました。1232年には武士のための初めての法律である御成敗式目ごせいばいしきもくを定め、土地争いを裁く基準をはっきりさせます。

  1. 源氏の将軍が3代で絶える
  2. 上皇が幕府を倒す好機とみて挙兵
  3. 御家人が幕府側について圧勝
  4. 幕府が朝廷より優位に。北条氏の執権政治が固まる
  • 1203北条時政ほうじょうときまさが実権を握る（執権のはじまり）
  • 1219源実朝が暗殺され、源氏の将軍が絶える
  • 1221承久の乱／六波羅探題を設置
  • 1225連署・評定衆を設置
  • 1232御成敗式目を制定
3

元寇

1268〜1297外交政治

13世紀、モンゴル帝国はユーラシア大陸の大部分を支配していました。中国を治めるため国号を元とした皇帝フビライは、朝鮮半島の高麗こうらいを従えたあと、日本にも従うよう国書を送ってきます。若い執権しっけん北条時宗ほうじょうときむねはこれを拒みました。

1274年、元と高麗の軍が対馬・壱岐いきを経て博多湾に上陸します（文永の役ぶんえいのえき）。集団で戦う戦法や火薬を使った武器に御家人ごけにんは苦戦しましたが、元軍は一日で船に引き揚げ、まもなく撤退しました。幕府は博多湾の沿岸に石の防塁ぼうるいを築き、九州の御家人に警備を命じて次に備えます。1281年には、滅ぼされた南宋なんそうの兵も加えた大軍が再び攻めてきましたが（弘安の役こうあんのえき）、防塁と御家人の抵抗で上陸を阻まれ、暴風雨で大きな損害を受けて敗退しました。

勝ったとはいえ、これは外国から国を守る戦いでした。敵の土地を奪ったわけではないので、御家人に分け与える新しい領地がありません。御家人は戦いの費用を自分で負担したうえ、3度目の襲来に備えて警備を続けなければなりませんでした。さらに、領地を子どもたちで分けて相続する習慣のために、一人あたりの領地はもともと小さくなっていました。

幕府は1297年に永仁の徳政令えいにんのとくせいれいを出し、御家人が手放した土地をただで取り戻せるようにしましたが、効果は一時的でした。一方で北条氏の本家（得宗とくそう）とその家臣への権力集中が進み、ほかの御家人の不満は高まっていきます。

  1. 防衛戦なので、新しい領地が手に入らない
  2. 恩賞がほとんど出ず、戦費も自分持ち
  3. 分割相続も重なり、御家人が困窮
  4. 北条氏本家（得宗）が権力を独占
  5. 「御恩ごおんと奉公ほうこう」がゆらぎ、幕府への不満が広がる
  • 1268フビライの国書が届く。時宗が執権に
  • 1274文永の役
  • 1276博多湾に防塁を築き始める
  • 1281弘安の役
  • 1297永仁の徳政令
4

鎌倉幕府の滅亡と建武の新政けんむのしんせい

1297〜1336政治

この頃、天皇家は2つの系統（持明院統じみょういんとうと大覚寺統だいかくじとう）に分かれて皇位を争っており、幕府がその調整役になっていました。大覚寺統の後醍醐天皇ごだいごてんのうは、天皇自らが政治を行うことを目指し、幕府を倒そうと2度計画しますが、いずれも失敗して隠岐おきに流されます。

それでも、幕府に不満を持つ武士や、楠木正成くすのきまさしげのような新しい勢力が各地で立ち上がりました。1333年、幕府の有力御家人ごけにんだった足利尊氏あしかがたかうじ（当時は高氏）が幕府を裏切って京都の六波羅探題ろくはらたんだいを攻め落とし、新田義貞にったよしさだが鎌倉を攻めて北条氏を滅ぼします。約150年続いた鎌倉幕府はこうして倒れました。

京都に戻った後醍醐天皇は建武の新政を始めます。しかし、土地の権利を認めるには天皇の命令書が必要とされたため、手続きが滞って混乱しました。恩賞も公家くげに厚く武士に薄いと受け取られ、武士の政治を望む声は尊氏に集まります。1335年に反乱をしずめるため関東へ向かった尊氏は、そのまま新政に背き、新政はわずか2年あまりで崩れました。

  1. 御家人の不満と、皇位をめぐる天皇家の対立
  2. 後醍醐天皇が倒幕を呼びかける
  3. 足利尊氏・新田義貞が幕府を裏切り、滅ぼす
  4. 天皇中心の新政が武士の期待に応えられない
  5. 尊氏が離反。武士の政権が再びつくられる
  • 1324正中の変しょうちゅうのへん（最初の倒幕計画が発覚）
  • 1331元弘の変げんこうのへん（2度目の計画、天皇は隠岐へ）
  • 1333鎌倉幕府の滅亡
  • 1334建武の新政が始まる
  • 1335中先代の乱なかせんだいのらん。尊氏が新政に背く
5

南北朝の動乱

1336〜1392政治

1336年、尊氏たかうじは京都を押さえ、持明院統じみょういんとうの天皇（北朝）を立てて、政治の方針（建武式目けんむしきもく）を示しました。これが室町幕府の始まりです。一方、後醍醐天皇ごだいごてんのうは奈良の吉野よしのに逃れて、自分こそ正統な天皇だと主張しました（南朝）。こうして2人の天皇が並び立つ時代が約60年続きます。

動乱が長引いたのは、南朝が強かったからではありません。幕府の内部でも、尊氏と弟の直義ただよしが争う観応の擾乱かんのうのじょうらんが起こり、負けそうになった側が南朝と手を結ぶことを繰り返したからです。各地の武士も、一族の中や近所の相手と争うたびに北朝・南朝のどちらかを名乗りました。

この戦乱の中で強くなったのが、国ごとに置かれた守護しゅごです。幕府は戦費を集めさせるため、荘園しょうえんの年貢の半分を守護が取り立てることを認めました（半済令はんぜいれい）。守護はその土地を地元の武士に分け与えて家来にし、国全体を自分の領地のように治める守護大名へと成長していきます。

  1. 2つの朝廷が並び、どちらにも大義名分がある
  2. 幕府の内紛のたびに、負けた側が南朝と結ぶ
  3. 幕府は戦いのため守護に大きな権限を与える
  4. 守護が国を支配する「守護大名」になる
  • 1336尊氏が北朝を立て建武式目を示す／後醍醐天皇が吉野へ
  • 1338尊氏が征夷大将軍せいいたいしょうぐんに
  • 1350観応の擾乱（〜1352）
  • 1352半済令
  • 1392南北朝の合一

足利義満あしかがよしみつと東アジア

1368〜1428政治外交

3代将軍足利義満の時代に、室町幕府は最も強くなります。京都の室町に「花の御所」と呼ばれる邸宅を構え、力をつけすぎた守護しゅご大名を戦いで抑えました。1392年には南朝に働きかけて南北朝の合一を実現し、のちに将軍を辞めて太政大臣だいじょうだいじんにもなり、武家と公家くげの両方の頂点に立ちます。

この頃、東アジアも大きく変わっていました。中国では1368年に漢民族の明が元を北へ追い、朝鮮半島では1392年に朝鮮（李氏朝鮮）が建国されます。どちらも、朝鮮半島や中国の沿岸を荒らす日本人中心の海賊倭寇わこうに悩まされていました。

明は、周りの国の王が皇帝に貢ぎ物を送り、皇帝が王として認めて返礼を与える冊封さくほうの関係しか認めませんでした。義満は1401年に明へ使いを送り、「日本国王」として認められます。1404年から始まった日明貿易では、正式な船であることを示す合札（勘合かんごう）を使ったので勘合貿易とも呼ばれます。銅銭が大量に輸入され、日本の貨幣経済を支えました。

  • 1368明が建国。義満が将軍に
  • 1392南北朝の合一／朝鮮が建国
  • 1401義満が明に使いを送る
  • 1404勘合貿易の開始
  • 1419応永の外寇

幕府の動揺と応仁の乱おうにんのらん

1428〜1477政治

義満よしみつのあと、将軍の力はしだいに弱まります。6代将軍足利義教あしかがよしのりはくじ引きで選ばれた将軍で、権威を取り戻そうと強い態度で守護しゅご大名にのぞみ、関東で幕府に逆らった鎌倉公方かまくらくぼうを滅ぼしました（永享の乱えいきょうのらん）。しかし1441年、処罰を恐れた守護大名の赤松満祐あかまつみつすけに殺されてしまいます（嘉吉の変かきつのへん）。将軍が家臣に殺されたことで、幕府の権威は大きく傷つきました。

同じ頃、民衆も力をつけていました。村の人々は団結して自治を行い（惣村そうそん）、借金の帳消しを求めて土倉どそうや酒屋を襲う土一揆つちいっきを起こします。

8代将軍足利義政あしかがよしまさの時代、将軍の跡継ぎ争いに、管領かんれい家の畠山はたけやま氏・斯波しば氏の家督争い、そして有力者の細川勝元ほそかわかつもとと山名宗全やまなそうぜんの主導権争いが結びつき、1467年に応仁の乱が始まります。全国の守護大名が東軍と西軍に分かれて京都で11年も戦い、京都は焼け野原になりました。決着がつかないまま乱は終わりましたが、守護大名が京都で戦っているあいだに、地元では家臣や国人こくじんが力をのばしていました。

  1. 将軍の暗殺で幕府の権威が傷つく
  2. 将軍家・管領家の跡継ぎ争いがからみ合う
  3. 守護大名が二手に分かれ京都で11年戦う
  4. 守護の留守中に、地元の家臣や国人が実権を握る
  5. 将軍も守護も、地方を抑えられなくなる
  • 1428正長の土一揆しょうちょうのつちいっき
  • 1438永享の乱（鎌倉公方が滅ぶ）
  • 1441嘉吉の変（義教が殺される）
  • 1467応仁の乱が始まる（〜1477）
8

戦国時代

1477〜1573政治外交

応仁の乱おうにんのらんのあと、身分の低い者が実力で上の者を倒す下剋上げこくじょうの風潮が広がります。1485年には山城やましろ（京都府南部）で国人こくじんと農民が守護しゅごの軍を追い出して自治を行い（山城の国一揆やましろのくにいっき）、1488年には浄土真宗じょうどしんしゅう（一向宗いっこうしゅう）の信者が加賀かがの守護を倒して約100年にわたり国を治めました（加賀の一向一揆いっこういっき）。1493年には管領かんれいの細川氏が将軍を交代させる事件（明応の政変めいおうのせいへん）も起こり、将軍は有力者に担がれる存在になります。

こうした中で、自分の力で一国以上を治める戦国大名が各地に現れます。守護大名から生き残った武田氏や今川氏、家臣から主家を乗っ取った朝倉氏あさくらし、そして伊豆・相模さがみを奪った北条早雲ほうじょうそううん（伊勢宗瑞いせそうずい）などです。戦国大名は独自の法律（分国法ぶんこくほう）を定め、城下町をつくり、鉱山の開発や治水にも取り組みました。

16世紀半ばには、ヨーロッパの人々がアジアの海に進出してきます。1543年、種子島たねがしまに漂着した船に乗っていたポルトガル人が鉄砲を伝え（1542年説もあり）、まもなく堺さかいや近江おうみの国友くにともで大量に作られるようになりました。1549年にはフランシスコ・ザビエルが鹿児島に来てキリスト教を伝え、ポルトガルやスペインの商人との南蛮貿易なんばんぼうえきも始まります。鉄砲は戦い方を変え、それを大量にそろえる経済力が勝敗を左右するようになりました。

1568年、尾張おわりの織田信長おだのぶながは足利義昭あしかがよしあきを15代将軍に立てて京都に入りますが、やがて対立し、1573年に義昭を京都から追放しました。これで室町幕府は事実上滅び、中世は終わりを迎えます。

  • 1485山城の国一揆
  • 1488加賀の一向一揆
  • 1493明応の政変
  • 1543鉄砲伝来
  • 1549ザビエルがキリスト教を伝える
  • 1560桶狭間おけはざまの戦い（信長が今川義元いまがわよしもとを破る）
  • 1573信長が足利義昭を追放、室町幕府が滅ぶ

なぜ近世へ移ったのか
  1. 応仁の乱おうにんのらんで将軍・守護しゅごの権威が失われる
  2. 戦国大名が自分の国を独自に治める
  3. 鉄砲と南蛮貿易なんばんぼうえきで、戦い方とお金の流れが変わる
  4. 経済力と鉄砲を握った大名が他を圧倒
  5. 織田信長おだのぶなが・豊臣秀吉とよとみひでよしによる全国統一へ
