生きる意味はどこから来るのか

『夜と霧』の要約から、ニーチェとの比較、「意味とは何か」まで。

  1. 『夜と霧』と著作権

    本の要約は頼める？ 『夜と霧』とか。

    • 著者はオーストリアの精神科医フランクル（1905〜1997）。強制収容所を生き延び、その体験を心理学者の目で書いた。原題は『一心理学者の強制収容所体験』（1946年）。
    • 収容者の心は、収容直後のショック、感情の麻痺、解放後の苦い失望、の3段階をたどった。
    • 極限でも、どういう態度をとるかを選ぶ自由は最後まで残る。未来に目的がある人ほど折れにくかった。

    こういう内容を教えて大丈夫？ 著作権は切れている？

    • 切れていない。日本では原則として死後70年まで保護されるため、2067年ごろまで続く。翻訳文も訳者の著作物として別に保護される。
    • 著作権が守るのは文章の表現で、考え方そのものではない。自分の言葉で要点を説明するのはよく、本文を長く書き写すのはよくない。
  2. ニーチェとのつながり

    「それでも人生にイエスと言う」は、ニーチェの言葉？

    • 違う。ブーヘンヴァルト強制収容所で囚人たちが歌った歌（作詞はレーナー＝ベーダ）の一節で、フランクルが別の本の題に使った。
    • ただ、人生を肯定する思想はニーチェにもある。運命愛、永劫回帰、人生に「然り」と言うこと。
    • 『夜と霧』は、なぜ生きるかを知る者はほとんどどんな苦境にも耐えられる、というニーチェの言葉（『偶像の黄昏』）を引いている。
  3. 人生の側から問われる

    人生の側から問われる意味とは、どういうこと？

    • 「人生に何を期待できるか」ではなく「人生が自分に何を期待しているか」と、問いの向きを逆にする。
    • 収容所で生きる望みを失った2人のうち、1人には帰りを待つ子どもが、もう1人には書きかけの研究書があった。代わりのいない自分に気づき、2人は力を取り戻した。
    • ドイツ語の「責任」には「答える」が含まれる。生きることは問いに答えることだ、とフランクルは考えた。
    • 答え方は3つある。何かをつくること、何かを体験し誰かを愛すること、避けられない苦しみにどういう態度をとるか。

    極限状況でも希望を失わないためのテクニック？

    • テクニックというより、物の見方の転換である。
    • 「良くなる」という希望とは違う。クリスマスには解放されると信じた囚人の多くが、そうならなかった直後に亡くなったという。
    • 結果がどうであれ、今の状況にどう応えるかに意味がある。後年、フランクルはこれを「悲劇の中の楽観主義」と呼んだ。
  4. 楽観的ニヒリズムとの違い

    ニーチェは楽観的ニヒリズムと言われることもある。悲劇の中の楽観主義とは違う？

    • 「楽観的ニヒリズム」は近年広まった言い方で、ニーチェ自身の言葉ではない。ニーチェは受動的ニヒリズムと能動的ニヒリズムを分け、ニヒリズムを乗り越えることを目指した。
    • 大きな違いは意味の出どころである。ニーチェ的な立場では意味は最初からなく、自分でつくる。フランクルでは意味は状況の中にすでにあり、自分で見つける。
    • 苦しみ・罪・死（悲劇の三要素）を含めて人生を肯定する、という点は共通している。
  5. 意味とは何か

    そもそも、意味って何？

    • 言葉の意味とは別に、人生や行為の意味がある。ざっくり言えば、それをする理由になるもの、やる価値があると感じられるもの。
    • 立場は分かれる。意味は状況の中にある（フランクル）、意味は人間がつくる（ニーチェ、サルトル）、本人が心から惹かれることと客観的な価値が重なるところに生まれる（スーザン・ウルフ）。
    • 一つの見方として、意味とは自分と、自分を超えた何かとのつながりだ、とまとめた。

    よくわからない。これから確実に死ぬ状況でも、生きる意味はある？

    • フランクルの答えは「ある」。死を目前にした若い女性は、窓の外の一本の木を友と呼び、穏やかに最期を過ごしていた。
    • 理由は2つ。何もできなくても、死にどう向き合うかは選べる。そして、生きたこと・愛したことは過去として確定し、消えない。
    • ただし、死ねば何も残らないので意味もない、と考える哲学者もいる。答えの分かれる問いである。
  6. 今と未来、自分と他人

    今と未来、自分と他人。この2つは似ている？

    • パーフィットは、未来の自分はある意味で他人に近いと考えた。未来の自分のためのがまんと、他人のためのがまんは、構造がほぼ同じになる。ネーゲルも同じ形の議論をしている。
    • 未来の自分を考えるときの脳の働きは、他人を考えるときに似ているという研究がある（ハーシュフィールドら）。
    • フランクルの意味には、外（未来・他人）へのつながりと、今ここの自分の態度の両方がある、と整理できる。

    それでは、意味の源泉がどこにあるのか、はっきりしないのでは？

    • その通りで、フランクルへの代表的な批判である。
    • フランクルは最後に、意味の源泉を人間には理解しきれない「超意味」に置いた。信仰に近く、根拠は説明されていないと言われる部分である。

キーワード

  • ヴィクトール・フランクル『夜と霧』

    強制収容所での体験を、精神科医の目で記録した本。日本では霜山徳爾訳と、読みやすい池田香代子訳（新版）がある。

  • ロゴセラピー

    フランクルが始めた心理療法。人が生きる意味を見つけることを助けて、心の回復を図る。不安をあえて望んでみる「逆説志向」などの技法もある。

  • 悲劇の中の楽観主義

    苦しみ・罪・死という避けられない三つ（悲劇の三要素）があっても、人生には意味があり、肯定できるとする考え方。

  • 運命愛（アモール・ファティ）

    起きたことを嫌々受け入れるのではなく、愛するところまで肯定するというニーチェの考え。

  • 永劫回帰

    この人生がまったく同じかたちで無限にくり返されるとしても、それを望めるか、とニーチェが投げかけた思考の試金石。

  • 受動的ニヒリズム・能動的ニヒリズム

    意味がないと知って無気力になるのが受動的、古い価値を壊して新しい価値をつくる力に変えるのが能動的。ニーチェの区別。

  • 超意味

    人間には理解しきれない、より大きな意味。フランクルが個々の意味の最終的な支えとして置いた考え。

  • スーザン・ウルフの「意味」

    本人が心から惹かれることと、客観的にも価値があることが重なったところに意味が生まれる、という現代の哲学者の考え。

  • パーフィットの人格の同一性

    未来の自分とのつながりは程度の問題にすぎない、とする議論。『理由と人格』で展開された。

  • 著作権の保護期間

    日本では原則として著作者の死後70年。翻訳は訳者の著作物として、原作とは別に保護される。保護されるのは表現で、考え方そのものではない。

課題

  • 意味の源泉はどこにあるのか。「超意味」は根拠になりうるのか
  • 意味は「見つける」ものか「つくる」ものか、それとも両方か
  • 未来の自分が他人に近いなら、自分を大切にする理由はどう変わるのか
